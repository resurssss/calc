# Калькулятор стоимости переезда

Интерактивный веб-калькулятор для предварительного расчёта стоимости переезда между городами. Пользователь последовательно заполняет информацию о маршруте, способе передвижения, количестве людей, багаже, жилье и дополнительных расходах, после чего получает ориентировочную итоговую сумму.

Проект реализован в формате пошаговой формы с адаптивным интерфейсом.

## Функциональность

Калькулятор состоит из четырёх этапов:

**1. Направление переезда**
- Выбор города отправления и назначения.
- Поиск городов с помощью выпадающих списков.
- Проверка корректности введённых данных.

**2. Перевозка**
- Указание количества взрослых, детей и животных.
- Выбор способа передвижения: самолёт, поезд/автобус или личный автомобиль.
- Выбор класса билета.
- Указание веса багажа.

**3. Жильё на первое время**
- Выбор варианта проживания: аренда, временное жильё или собственное жильё.
- Выбор типа недвижимости.

**4. Дополнительные расходы**
- Выбор необходимых дополнительных услуг.
- Выбор валюты расчёта: рубли, евро или доллары.

## Результат расчёта

После заполнения формы пользователь получает итоговую страницу, на которой отображаются:

- Выбранный маршрут.
- Ориентировочная стоимость переезда.
- Детализация расходов по категориям: билеты, жильё, перевозка вещей и дополнительные услуги.

Предусмотрена возможность скачать результат в формате `.txt` или заполнить калькулятор заново.

## Используемые технологии

- **HTML5** — структура страниц и элементов формы.
- **CSS3** — оформление интерфейса, адаптивная вёрстка и анимации.
- **JavaScript (Vanilla JS)** — логика калькулятора, обработка действий пользователя и динамическое обновление интерфейса.
- **JSON** — хранение исходных данных для расчётов.
- **Google Fonts** — подключение шрифта Unbounded.

Проект реализован без использования сторонних JavaScript-фреймворков.

## Структура проекта

| Файл | Назначение |
|---|---|
| `index.html` | HTML-разметка калькулятора |
| `styles.css` | Стили и адаптивная вёрстка |
| `script.js` | Логика работы и расчёта стоимости |
| `data.json` | Данные о городах, маршрутах и тарифах |


## Принцип работы

Все расчёты выполняются на стороне клиента с помощью JavaScript.

При запуске приложения загружается файл `data.json`, содержащий исходные данные о маршрутах, стоимости транспорта, жилья и дополнительных услуг.

После заполнения формы программа получает выбранные пользователем параметры, рассчитывает отдельные категории расходов, переводит суммы в выбранную валюту и формирует итоговый результат.

Поля формы динамически изменяются в зависимости от выбора пользователя. Например, при выборе личного автомобиля скрывается выбор класса билета, а при наличии собственного жилья — выбор типа арендуемой недвижимости.
